# Changelog

## 0.1.0

First preview release.

- Graph of lists, trees and graphs with cycles, redrawn at every pause, with pause history and node
  inspection.
- Recursion and sorting views.
- GDB (C/C++ extension) and LLDB (CodeLLDB), for C and C++, on Linux and Windows.
- The same visualization in the browser.
- Interface in English and Brazilian Portuguese.
